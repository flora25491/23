STALCRAFT BUY — проект Windows-приложения

В приложении есть локальные инструменты учёта:
- калькулятор стоимости и прибыли;
- учёт сделок и история;
- список AutoBuy с ручной проверкой цены;
- анализ вручную введённых рыночных цен;
- генератор рекламных сообщений;
- локальный AI Agent с командами-помощниками.

Программа не подключается к игровому клиенту, не принимает отряды,
не покупает предметы и не отправляет сообщения в игровой чат автоматически.

СБОРКА EXE БЕЗ УСТАНОВКИ NODE.JS НА СВОЙ КОМПЬЮТЕР (через GitHub)

1. Создай бесплатный аккаунт на https://github.com/ (если его ещё нет).
2. Создай новый пустой репозиторий (New repository).
3. Загрузи в репозиторий ВСЕ файлы и папки из этого проекта, включая скрытую
   папку .github и файл .github/workflows/build-windows.yml.
4. Открой вкладку Actions в репозитории.
5. Выбери слева “Build STALCRAFT BUY for Windows”.
6. Нажми “Run workflow”, затем зелёную кнопку “Run workflow”.
7. Дождись окончания сборки (обычно несколько минут), открой завершённый запуск.
8. Внизу страницы в разделе Artifacts скачай “STALCRAFT-BUY-Windows”.
9. Распакуй скачанный архив. Внутри будут EXE-файлы.

Сборка выполняется на сервере GitHub. Node.js и Python на компьютер
устанавливать не нужно. Нужны интернет и аккаунт GitHub.

Если хочешь собирать локально на Windows:
1. Установить Node.js LTS: https://nodejs.org/
2. Открыть терминал в папке проекта.
3. Выполнить npm install
4. Выполнить npm run dist:win
5. Результат появится в папке dist.
